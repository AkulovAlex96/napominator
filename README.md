# Напоминатор

Android-приложение гибких напоминаний (Kotlin, Jetpack Compose, Room). Данные только на устройстве.
Спецификация: [TZ.md](TZ.md). Макеты: [design/index.html](design/index.html).

## Сборка и установка

```bash
./gradlew :app:assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

Требуется JDK 17+, Android SDK 36, Android 8+ на устройстве, Google Play Services для геозон.

## Тесты

```bash
./gradlew :app:testDebugUnitTest              # логика расписаний, ячеек таблицы, JSON (быстро, без устройства)
./gradlew :app:connectedDebugAndroidTest      # на эмуляторе или телефоне: будильники, уведомления, UI, геозоны, Wi-Fi, миграция БД
```

Инструментальные тесты стирают данные приложения на устройстве, запускайте их на эмуляторе.
Эмулятору хватает `-memory 3072 -cores 3`; не держите вместе эмулятор и несколько Gradle-демонов (`./gradlew --stop`).

Отдельные классы: `-Pandroid.testInstrumentationRunnerArguments.class=app.napominator.WifiTest`.

## Тестовые данные

```bash
python3 tools/make_testdata.py                 # → testdata/testdata.json, история ~6 месяцев до сегодняшнего дня
python3 tools/make_testdata.py --days 90 --tz Asia/Novosibirsk -o /tmp/data.json
```

В наборе 18 напоминаний (все виды расписаний, три вида условий, пауза и архив, измерения с несколькими полями и накопительные),
около 2600 срабатываний, 1150 измерений и 3 набора привычек. Загрузка на телефон: положите файл в «Загрузки» и нажмите
«Ещё → Импорт из JSON». **Импорт заменяет все данные приложения.** Файл привязан к дате генерации, перегенерируйте его перед
показом, чтобы «сегодня» совпадало. Согласованность с правилами расписаний проверяет `TestDataTest`.

## Что нужно разрешить на телефоне

Экран «Ещё → Надёжность» показывает, чего не хватает, и ведёт в нужные настройки.

- Уведомления и точные будильники: без них напоминания опаздывают.
- Экономия батареи: «Не ограничивать». На Xiaomi, Samsung, Huawei, OnePlus включите ещё автозапуск.
- Критичные напоминания: разрешение на полноэкранные уведомления (Android 14+).
- Место и Wi-Fi: геолокация «Разрешить всегда». Для Wi-Fi она нужна, чтобы система отдавала имя сети, в том числе после перезагрузки.
- Bluetooth: разрешение «Устройства поблизости».

## Устройство кода

| Пакет | Что внутри |
|---|---|
| `data` | Room (сущности, DAO, миграция 1→2), `Schedule` (все виды расписаний), `Repo`, `Logic` (слоты и ячейки таблицы), резервные копии |
| `alarm` | `Alarms` (AlarmManager), `Notifier`, приёмники событий, `Conditions` (геозоны, служба слежения за Wi-Fi/Bluetooth) |
| `ui` | экраны Compose, редактор, карта (osmdroid), экран критичных напоминаний |
| `widget` | три виджета на Glance |

Отладочная сборка содержит `SeedReceiver` (загрузка тестовых данных, показ уведомлений); в релиз он не попадает.

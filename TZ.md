# ТЗ: Напоминатор (v1, зафиксировано)

## 1. Контекст
- Платформа: Android 8+ (API 26), нативный Kotlin, Jetpack Compose, Material 3.
- Аудитория: автор и несколько человек. Распространение APK, без магазина.
- Данные только на устройстве (Room/SQLite). Без аккаунтов и сервера.
- Язык: русский.
- Темы: светлая, тёмная, как в системе (по умолчанию).
- Устройства без Google Play Services не поддерживаются.

## 2. Сущность «Напоминание»
Название, заметка, чек-лист (необязательно), категория, теги, приоритет, тип (Задача / Измерение), триггер, поведение уведомления, статус (активно, пауза, выполнено, архив).

## 3. Триггеры
**Временные**
- Разовое: дата и время.
- Каждые N минут/часов/дней/недель/месяцев.
- По дням недели, одно или несколько времён в день.
- Дни месяца: число, последний день, «N-й день недели месяца».
- Ограничение: до даты или N раз.
- Окно «не беспокоить» (например 9:00–22:00).

**По условию**
- Геолокация: вход в зону / выход (точка на карте OSM, радиус от 100 м). Через Google Geofencing API.
- Wi-Fi: подключение / отключение от выбранной сети.
- Bluetooth: подключение / отключение выбранного устройства.
- Режим срабатывания: «каждый раз» с минимальным интервалом (по умолчанию 1 час, настраивается) или «один раз».
- Для Wi-Fi/Bluetooth используется foreground-сервис с постоянной иконкой (включается только если есть такие напоминания).

**Комбинации**: условие + временное окно; несколько условий через «или».

## 4. Уведомление
- Действия: «Выполнено», «Отложить» (пресеты и свой вариант), «Пропустить».
- Для измерения: поле ввода значения прямо в шторке (RemoteInput), запасной вариант: небольшое окно ввода.
- Настойчивый режим: повтор каждые N минут до отметки, с лимитом.
- Приоритеты: Обычный; Важный (свой звук и вибрация); Критичный (полноэкранный показ поверх блокировки).
- Свой звук для категории.

## 5. Измерения (трекер значений)
- Название величины, единица измерения (вводится вручную, приложение запоминает введённые и подсказывает).
- Тип значения: число, дробное, оценка 1–5/1–10, да/нет.
- Диапазон и шаг, подстановка прошлого значения.
- Несколько полей в одном напоминании (например, давление верхнее/нижнее + пульс).
- Накопительный режим (вода: +250 мл несколько раз за день, график по суммам).
- Пропущенный замер на графике не отмечается.
- Ввод: уведомление, виджет, карточка, задним числом.
- Просмотр: линейный график (неделя/месяц/3 месяца/год/всё), мин/макс/среднее/изменение/тренд, целевая линия, подсветка выхода из диапазона, таблица значений с правкой.
- Экспорт значений в CSV.

## 6. Календарь
- Виды: месяц, неделя, день.
- Будущие срабатывания из правил повтора; прошлые из истории (выполнено / пропущено / отложено).
- Точки плотности на днях, фильтр по категориям и тегам.
- Тап по дню открывает список, долгий тап создаёт напоминание на дату.
- Без интеграции с системным календарём.

## 7. Таблица привычек («Неделя» / «Месяц»)
- Строки: выбранные напоминания; столбцы: дни.
- Режимы: Неделя (крупно) и Месяц (компактный heatmap). Прошлые периоды доступны (стрелки, свайп, выбор периода).
- Состояния ячейки: ✓ выполнено, – пропущено, → перенесено, число (значение измерения), пусто (нет срабатывания / будущее), сегодняшний столбец подсвечен.
- «Пропущено» ставится автоматически в конце дня. Любое состояние можно поменять вручную, в том числе задним числом; выполнение задним числом остаётся обычным ✓.
- Несколько срабатываний в день: «2/3», цвет (зелёный полностью, жёлтый частично). Накопительные: сумма за день.
- Тап: отметить выполнение (для измерения открывается ввод). Долгий тап: меню (выполнено, пропущено, перенести, комментарий, изменить значение). Тап по названию: карточка / график.
- Наборы строк («Здоровье», «Дом» …): выбор галочками, порядок перетаскиванием, быстрый набор по категории.
- Итоги: справа доля выполненных за период (5/7) или среднее для измерений; внизу процент по дням; серия подряд (streak) в карточке.
- Начало недели настраивается (по умолчанию понедельник). Названия строк закреплены при горизонтальной прокрутке.
- Экспорт таблицы в CSV.

## 8. Виджеты
- Ближайшие напоминания: отметка выполнения, кнопка быстрого добавления.
- Привычки на сегодня: отметка в один тап.
- Измерение: мини-график и кнопка быстрого ввода.

## 9. Импорт / экспорт
- JSON одним файлом (напоминания, категории, теги, наборы, история, измерения) через системный выбор файла (SAF).
- Опционально автобэкап в выбранную папку по расписанию.
- CSV для таблиц и значений.

## 10. Навигация и экраны
Нижние вкладки: Сегодня · Неделя (таблица) · Календарь · Графики · Ещё.
Экраны: список «Сегодня / Предстоящие / Все / Архив» с поиском и фильтрами; создание/редактирование с конструктором расписания; карточка с историей; категории и теги; настройки; «Надёжность» (экономия батареи, точные будильники, разрешения, инструкции для Xiaomi/Samsung и др.).

## 11. Технические решения и риски
- Точные будильники `setExactAndAllowWhileIdle`, разрешение SCHEDULE_EXACT_ALARM (Android 12+), пересчёт после перезагрузки, смены времени и часового пояса.
- Геозоны требуют фонового разрешения на геолокацию (многоступенчатая выдача).
- Агрессивная экономия батареи у производителей: экран «Надёжность».
- MVVM, Room, Hilt, WorkManager.

## 12. Вне рамок v1
Синхронизация, облако, интеграция с календарём, зависимые напоминания, свободный текстовый ввод, iOS, другие языки, устройства без Play Services.
